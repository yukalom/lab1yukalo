# Додаткові критерії ЛР4 — реалізовано

У проєкті були додані/виправлені всі критерії з блоку додаткових завдань за бонусні бали.

## 1. Пагінація, фільтрація та сортування

Реалізовано на API та фронтенді для основних списків:
- `software`
- `license`
- `user`
- `request`

Що зроблено:
- API приймає `limit`, `offset`, `q`, `sortBy`, `sortDir`.
- На бекенді використовується `LIMIT` / `OFFSET`.
- Додано коректний підрахунок загальної кількості записів через `COUNT(*)`.
- Пошук виправлено за реальними полями таблиць, а не за неіснуючим `title`.
- Додано сортування за `id` та основними полями кожної сутності.
- На фронтенді додано/виправлено кнопки `Previous` / `Next`, пошук і кліки по заголовках таблиць.

Основні файли:
- `backend/src/repositories/SoftwareRepository.ts`
- `backend/src/repositories/licenseRepository.ts`
- `backend/src/repositories/userRepository.ts`
- `backend/src/repositories/requestRepository.ts`
- `frontend/src/Api/SoftwareApi.ts`
- `frontend/src/Api/LicenseApi.ts`
- `frontend/src/Api/UserApi.ts`
- `frontend/src/Api/RequestApi.ts`
- `frontend/src/Sections/*/*List.render.ts`
- `frontend/src/Sections/*/*.event.ts`

## 2. Кешування на фронтенді

Кешування реалізовано централізовано в `frontend/src/Api/ApiClient.ts`.

Що зроблено:
- Успішні `GET` / `HEAD` запити кешуються на 30 секунд.
- При повторному відкритті того самого списку або повторному запиті з тими самими параметрами дані беруться з кешу без зайвого мережевого запиту.
- Після небезпечних змінювальних запитів `POST`, `PUT`, `PATCH`, `DELETE` кеш автоматично очищується.
- Це забезпечує інвалідацію кешу після `create/update/delete`.

Основний файл:
- `frontend/src/Api/ApiClient.ts`

## 3. Retry для безпечних запитів

Retry реалізовано централізовано в `frontend/src/Api/ApiClient.ts`.

Що зроблено:
- Повторюються тільки безпечні запити `GET` / `HEAD`.
- Повтор виконується тільки для статусів `429` і `503`.
- Кількість повторів обмежена двома спробами.
- Якщо сервер повертає заголовок `Retry-After`, він враховується.
- Для `POST`, `PUT`, `PATCH`, `DELETE` retry не виконується, щоб випадково не створити/не змінити дані кілька разів.

Основний файл:
- `frontend/src/Api/ApiClient.ts`
